# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware refers to the physical components of a computer or electronic system that you can touch. It includes devices such as the motherboard, processor, memory, storage drives, keyboard, mouse, and monitor. Hardware works together with software to perform tasks, process data, store information, and enable communication between users and machines.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software interact to make a computer function effectively. Hardware provides the physical components such as the processor, memory, and input/output devices. Software gives instructions that tell the hardware what to do. The operating system acts as a bridge, allowing applications to communicate with hardware and perform tasks like processing, storing, and displaying information
